# 새 출발의 기준

2026-09-17. 기존 프로젝트는 참고 및 에셋 보관용으로 보존한다. 기존 설정과 구현을 새 프로젝트의 의무 조건으로 가져오지 않는다.

## 사용자가 남기기로 한 것

- 탑뷰 탐험, 턴제 전투, 스토리 중심의 게임.
- 거대한 무언가와 마주하는 코즈믹 호러, 어둡고 미스터리한 분위기.
- 참고작: 언더테일, 피어 앤 헝거. 세부 시스템을 그대로 채택한다는 뜻은 아니다.
- 전투 구도: 오른쪽 적, 왼쪽 등불, 등불에서 뻗는 빛이 각각 UI 버튼.
- 거대한 적은 되도록 로우앵글. 탐험의 탑뷰와 조우·전투의 시점을 구분한다.
- 기존 조우 연출은 참고 후보다. 모든 연출 단계가 유지 확정된 것은 아니다.

서고 배치, 꿈과 결사의 세부 설정, 필터 강도, 자원 수치 등은 재검토 대상으로 둔다.

## 이후 함께 정한 서고 방향

- 서고는 게임의 튜토리얼이며, 세계관 몰입이 목적이다.
- 거대한 실내 도서관의 큰 홀. 책과 가구는 남아 있지만 사람이 없고 먼지가 쌓여 오래 방치되었다. 조용하고 으스스하다.
- 입구에서 홀 저편의 그것이 보여 시선을 끈다.
- 사용자가 직선 접근을 수정했다: 무너진 기둥·부서진 서가 같은 환경으로 움직임을 유도하고, 그것으로 향하는 길목에서 읽을거리를 읽게 한다. 큰 홀 안의 우회 동선이며 장애물 개수·기록 수·세부 배치는 미정이다. 원래 대부분의 책과 가구는 남아 있고, 일부 붕괴가 이동 경로를 만든다.
- 다음 피드백: 서고를 조금 더 크게 해도 좋고, ㄹ자 경로를 강하게 강제할 필요는 없다. 장애물이 홀을 가로막는 형태보다 부분적으로 돌아갈 수 있는 넓은 배치를 우선 검토한다. 기록으로 유도하는 목적은 유지한다.
- 최신 진행 조건: 읽을거리를 모두 읽으면 열리는 장치가 있어야 한다(사용자). 읽는 순서는 자유롭게 두며 이전의 '읽기 잠금 없음' 제안은 변경됐다. 조우 단상 앞 격자문과 문양·금속음 반응은 assistant의 제안이고 사용자 확정은 아니다. 기록 수와 구체적인 해제 장치는 미정이다.
- 그것은 기존 디자인을 새로 만들되, 눈으로 덮인 교차하는 여러 고리와 중심 눈을 유지한다. 천사 같은 인상이며 날개·깃털·사람 몸은 없다.
- 진행 초안에 사용자 동의: 입장과 이동 → 짧은 기록 및 상호작용 → 작은 위협을 통한 턴제·등불 메뉴 학습 → 그것과의 마주섬. 책을 전부 읽게 하는 진행 잠금은 두지 않는 방향.
- 부위 파괴 시스템을 넣고 싶다는 요청이 있다. 구체적인 부위·파괴 효과·튜토리얼에서의 교육 여부는 미정이다.
- 캐릭터는 현재 손대지 않고 서고 기획을 진행한다.
- 이번 일러스트는 입구에서 바라보는 분위기·규모 검토용이다. 실제 탐험은 탑뷰이며, 일러스트의 투시 시점을 탐험 카메라로 확정하지 않는다.

## 방랑자 첫 시안

기존 게임의 실제 참조: game_4/assets/characters/pilgrim_rot/walk/{south,north,east,west}/0.png.
현재 형식은 작은 후드 인물, 네 방향, 몸과 별도 등불이다. 이 모습은 참조이며 새 디자인의 확정 조건은 아니다.
먼저 네 방향 정지 자세의 디자인을 비교하고, 통과한 디자인으로 게임용 픽셀 파일과 걷기 동작을 만든다.
생성 이미지의 도트풍 외관과 실제 게임용 픽셀 규격을 구분한다.

## QA 기준 제안

| 항목 | 통과 기준 | 확인 방법 |
|---|---|---|
| 실루엣 | 작은 크기에서도 후드·몸·발이 분리되어 보이며 사람으로 읽힌다 | 실제 표시 크기와 검은 실루엣으로 확인 |
| 시점 | 네 방향 모두 동일한 탑뷰 각도·신체 비율이다 | 앞·뒤·좌·우 나란히 비교 |
| 방향 일관성 | 후드, 옷 길이, 장식, 색이 같은 인물로 이어진다 | 비대칭 장비는 좌우 반전으로 손이 바뀌지 않는지 확인 |
| 픽셀 규격 | 확정한 프레임 크기와 격자를 준수한다 | 첫 비교 기준은 기존 16×32. 새 규격이 필요하면 모든 방향에 함께 적용 |
| 픽셀 선명도 | 의도하지 않은 흐림·보간·서브픽셀 선이 없다 | 원본 배율 및 최근접 정수배 확대 |
| 투명 배경 | 배경과 체크무늬가 구워져 있지 않고 가장자리에 색 테가 없다 | 알파 채널과 밝은색·어두운색 배경 합성 확인 |
| 명암 | 밝고 어두운 바닥에서 몸의 윤곽과 방향이 읽힌다 | 필터 끔/켬, 등불 밝음/어두움 상태에서 확인 |
| 발 기준점 | 방향과 프레임이 바뀌어도 발의 기준점이 튀지 않는다 | 동일 좌표에 겹쳐 재생 |
| 여백·분리 | 신체가 잘리지 않고 프레임 경계를 넘지 않는다 | 전체 알파 경계와 시트 셀 검사 |
| 등불 | 몸 그림에 빛 번짐을 굽지 않고 별도 등불과 자연스럽게 겹친다 | 네 방향의 위치·가림 순서 확인 |
| 걷기 | 발이 교대로 움직이고, 몸 크기·옷 디테일이 불규칙하게 변하지 않는다 | 느리게 및 실제 속도로 반복 재생 |
| 실제 게임 | 이동·정지·방향 전환 시 떠 보이거나 미끄러지지 않는다 | 테스트 맵에서 충돌 위치와 함께 확인 |

첫 정지 시안에서는 걷기 항목을 미검증으로 남긴다. 시안 승인과 게임 투입 승인은 구분한다.
필수 실패: 방향 혼동, 다른 인물처럼 변형, 발 위치 점프, 배경 잔류, 흐린 픽셀, 신체 잘림.
게임에 넣기 전에는 규격·알파 검사와 실제 엔진 표시를 모두 확인한다.
