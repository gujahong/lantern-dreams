# 네 방향 정지 스프라이트 v2 — QA 미통과

사용자가 v1 디자인을 긍정적으로 평가하고 정지 스프라이트 제작 진행에 동의했다.
내장 image_gen으로 v1을 참조해 제작했다. 결과 파일: wanderer-idle-v2-draft.png.

목표는 프레임당 32×48, 네 프레임 128×48, 실제 알파 투명 배경이었다.
실제 결과는 2048×768이며, 8픽셀 간격 알파 검사에서 비불투명 표본은 0이었다. 체크무늬가 남아 있다.
디자인은 유사하게 유지되었지만 실제 게임용 규격과 투명도는 실패했다. 걷기 제작과 게임 연결을 완료했다고 취급하지 않는다.
생성만으로 같은 기술적 결함이 반복되므로, 다음 작업은 픽셀 편집을 통한 규격화·배경 제거·기준점 정렬이 필요하다.

## 프롬프트 전문

Use case: identity-preserve. This is an EDIT of the approved hooded wanderer four-direction sprite design. Preserve the character exactly: charcoal gray hood, completely black concealed face, muted taupe edging, long coat, small dark boots, identical proportions and costume. Produce the GAME ASSET itself, not a presentation or mockup. Remove the baked checkerboard completely and replace it with genuine alpha transparency everywhere outside the characters including holes between arms and body and legs. No checkerboard pixels in output. Four idle poses in a single row in the SAME order: south/front, west/left, north/back, east/right. Target actual output dimensions 128 pixels wide by 48 pixels tall, four exact 32x48 cells. Each character centered in its cell at x=16, feet baseline y=45, top of hood y=3, no overlap between cells. Construct crisp native pixel art on that grid, limited 12-color palette, no anti-aliasing, no gradients, no fuzzy outline, no partial transparency. Slight high top-down RPG view across all four poses; preserve approved silhouette while showing a little hood top. No lantern, glow, weapons, shadows, floor, labels, lines, border or padding outside the four cells. Important: actual low-resolution sprite sheet PNG, not an enlarged imitation of pixels. Prioritize real transparent background and consistent same-character four directions. If exact canvas dimensions are unsupported, retain extremely clean uniform square pixel clusters and isolated transparent sprites rather than adding any presentation background.
