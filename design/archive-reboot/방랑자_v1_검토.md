# 방랑자 v1 — 디자인 시안, 게임 투입 불가

생성: 내장 image_gen. 기존 앞·뒤 스프라이트를 참조했다.
파일: wanderer-concept-v1.png (1774×887).

## 확인 결과

- 네 방향과 후드·무채색 로브의 디자인은 비교할 수 있다.
- 기존보다 머리 비중과 몸 폭이 커서, 작은 방랑자보다는 귀여운 인상에 가까워졌다. 원하는 비율인지 검토가 필요하다.
- 탑뷰용으로는 위에서 내려다보는 각도가 약하다.
- 픽셀 크기가 균일한 실제 16×32 스프라이트가 아니다. 큰 시안을 단순 축소해 완성본으로 취급하지 않는다.
- 투명 배경 요청이 지켜지지 않았다. 체크무늬가 보이며 8픽셀 간격으로 조사한 알파 24,642개가 모두 255였다.
- 정지 자세 시안만 생성했다. 발 기준점 정렬, 걷기 루프, 게임 안 가독성은 미검증이다.

현재 판정: 디자인 논의용으로만 사용. 실제 게임용으로는 규격·시점·알파를 수정하고 다시 검사해야 한다.

## 생성 프롬프트 전문

Use case: stylized-concept. Create a first sprite design preview for a dark mysterious cosmic horror top-down story RPG. Input images are visual REFERENCES, not edit targets: tiny front and rear pixel sprites of the existing hooded wanderer. Keep the recognizable slender hooded wanderer, hidden dark face, worn charcoal gray and muted taupe/brown long travelling clothes, small boots, subdued trim. No new lore, weapons, backpack, horns, eyes glowing, or decorations. Make ONE clean four-direction idle sprite sheet: four equally spaced sprites in one horizontal row, order front facing south, left profile west, back north, right profile east. Consistent high top-down RPG camera angle across all four, identical body proportions, same clothes and palette, same baseline, no cropped parts. Old-school genuine low resolution pixel-art construction with coarse deliberate square pixel clusters, aiming for the visual economy of a 16 by 32 pixel character shown at a large exact integer scale for review; do NOT make a detailed high resolution painting with a pixel filter. Restrained 8 to 12 colors, hard pixel edges, no antialiasing, no gradients. Not chibi. Transparent background, no baked checkerboard, no floor, no cast shadow, no text, no panels, no grid, no labels. Do not draw any lantern or lighting glow into the character: the game adds the lantern separately. This is a design reference sheet for inspection, not a promise of import-ready 16x32 file dimensions.
